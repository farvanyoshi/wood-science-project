# Structural Enhancement of Wood through Chemical Treatment and Thermo-Mechanical Densification

A senior-year science project by Nirvan Joshi and Nathaniel Erickson, written up as an APA research paper and a
presentation board. Both are typeset with [Typst](https://typst.app).

Blocks of Southern Yellow Pine were **partially delignified** by boiling in an alkaline sodium hydroxide / sodium
sulfite bath (after Song et al., 2018), neutralized in citric acid, and then **hot-pressed** at 3–7 MPa in a
home-built heated steel press. The densified wood was cut into segments and tested for density, three-point
flexural strength (read from video of the press gauge with a small OpenCV tool) and Charpy impact energy.

## Key results

| | 3 MPa | 4 MPa | 5 MPa | 6 MPa | 7 MPa |
|---|---|---|---|---|---|
| Density (g/cm³) | 0.27 | 0.53 | 0.60 | **0.77** | 0.54 |
| Modulus of rupture (MPa)\* | 60 | 137 | 163 | 183 | **192** |
| Strength-to-weight (kN·m/kg)\* | 213 | 264 | 275 | 228 | **352** |

\* Means over five segments, with the 4 MPa outlier excluded. All values are generated in `data/processed/summary.csv`.

- The modulus of rupture rose steadily with pressing pressure, to about **2.8×** that of untreated pine (≈ 68 MPa).
- The best specific strength (**352 kN·m/kg** at 7 MPa) is about three times that of 6061 aluminium (≈ 115 kN·m/kg).
- 5–6 h of delignification left the Charpy impact energy roughly unchanged (≈ 4–6 J). 8 h of delignification cut it to about 0.24 J.

## Repository layout

```
paper.typ, poster.typ   document entry points (research paper, presentation-board summaries)
paper/, poster/         section text
lib/                    shared Typst code: package versions, data access, figure/table builders, quoted values
data/raw/               measurements as recorded (see data/README.md for units, sources and known discrepancies)
data/processed/         generated by the analysis pipeline; read directly by Typst
analysis/               `woodlab`: standard-library-only Python pipeline + tests + verification script
tools/gauge_reader.py   OpenCV tool that reads peak loads from videos of the analog press gauge
assets/images/          photographs and diagrams
references/refs.bib     bibliography
docs/VERIFICATION.md    every number in the original paper compared with the recomputed value
```

## Building

Requirements: [Typst](https://github.com/typst/typst) ≥ 0.15 (tested with 0.15.1) and Python ≥ 3.10. No Python
packages are needed for the pipeline. The gauge reader needs `opencv-python` (`tools/requirements.txt`).

```sh
make            # regenerate data/processed, then build/paper.pdf and build/poster.pdf
make test       # run the pipeline tests
make verify     # regenerate docs/VERIFICATION.md
make check      # tests + fail if the committed processed data is stale
```

You can also build without `make`:

```sh
cd analysis && python -m woodlab build && cd ..
typst compile paper.typ build/paper.pdf
typst compile poster.typ build/poster.pdf
```

On the first compile Typst downloads the packages pinned in `lib/style.typ` (versatile-apa, lilaq, unify, typsium).
GitHub Actions runs the tests and builds both PDFs on every push. The PDFs are attached to each run as artifacts.

### Changing the data

Edit a file in `data/raw/`, run `make`, and every figure, table and quoted number in both documents updates. For
example, to use a different test span, change `span_mm` in `data/raw/vc_segments.csv`. The pipeline checks the
inputs (missing columns, non-positive values, a span longer than its segment, unknown exclusions) and reports the
file and line of any problem.

## Data provenance and corrections

This repository was rebuilt from the original project files, the rough-draft data tables and the lab logbook.
Recomputing everything from the raw measurements corrected several hand-typed summary values and changed the span
used for the 6 and 7 MPa blocks. Every difference from the originally submitted paper, and its cause, is listed in
[`docs/VERIFICATION.md`](docs/VERIFICATION.md). The data decisions are documented in [`data/README.md`](data/README.md).

## Installing Typst

- Prebuilt binary (Linux x86-64):
  ```sh
  curl -L https://github.com/typst/typst/releases/latest/download/typst-x86_64-unknown-linux-musl.tar.xz | tar -xJ -C /tmp
  install /tmp/typst-x86_64-unknown-linux-musl/typst ~/.local/bin/
  ```
- With Rust: `cargo install --locked typst-cli`
- macOS: `brew install typst`. Windows: `winget install --id Typst.Typst`
- Check the install with `typst --version`.
